# Typography — 文字

型級、最小字級、字寬估算、版面最佳化。文字角色定義在 `roles.md`。

## 型級

| 層級 | 尺寸 | 字重 | 顏色 |
|---|---|---|---|
| L1 標題（嵌在圖內） | 36–44 | 700 | `ink-strong` 或 `accent` |
| L2 區域標題 | 20 | 700 | `cat-N-label` |
| L2 卡片標籤 | 20 | 700 | `ink-strong` |
| L3 子卡片、軌道副標 | 14 | 700 | `ink-muted` |
| L3 註解、來源 | 12 | 500 | `ink-muted` |

L1 常被漏掉。圖會被單獨轉貼，**必須自己解釋自己**。
唯一例外是嵌在文件裡當插圖時（embedded mode），由宿主標題承擔。

---

## 字級綁畫布寬度，不用絕對 px

SVG 會縮放。顯示大小是 `容器寬 ÷ 畫布寬 × 字級`，所以絕對 px 沒有意義——
`14px` 在 800 寬的圖裡正常，在 1600 寬的圖裡只剩一半大。

**畫布變大不會讓字變好讀**，兩者等比。塞不下時放大畫布，只是讓相對字級更小。

## 最小字級表

比例相對於**畫布寬度**（`viewBox` 的 W）。

| 角色 | 最小 | 建議 | 1100 寬時 |
|---|---|---|---|
| `text/title` | 3.5% | 4.0–5.0% | 39 / 44–55 |
| `text/section` | 2.4% | 2.6–3.0% | 26 / 29–33 |
| `text/body` | 2.0% | 2.2–2.5% | 22 / 24–28 |
| `text/support` | 1.6% | 1.8% | 18 / 20 |
| `text/caption` | 1.4% | 1.5% | 15 / 17 |
| `text/kicker` | 1.4% | 1.5% | 15 / 17 |

**最小值是硬底線**，不是建議。低於它的圖在投影或列印後會有人讀不到。

CJK 比拉丁字更早失去辨識度——筆畫密度高，縮小時先糊掉。
中文圖表取表中的**建議值**而非最小值。

### 校準來源

| 場合 | 顯示寬 | 最小內文 | 比例 |
|---|---|---|---|
| 文件插圖（A4 單欄） | 6.5" = 468pt | 9pt | 1.9% |
| 投影片（16:9） | 13.3" = 958pt | 18pt | 1.9% |

兩個差異極大的場合收斂到同一個數字，所以 2% 這條線相當穩。

## 版面最佳化的定義

「最佳化」不是模糊的美感判斷。目標依序如下，**前兩項是硬約束，不可交換**：

1. **可讀性** — 每個文字 ≥ 其角色最小字級。
2. **完整性** — 每個文字完全落在其容器內，無溢出、無裁切。
3. **對齊** — 所有框落在 8 單位格線上，同列間距一致。
4. **均衡** — 各列／各群組的視覺重量相近。單列節點數不應超過其他列的兩倍。
5. **緊湊** — 在上述前提下，畫布面積最小。

3–5 是軟目標，依序讓步。1 和 2 不讓步。

## 塞不下時的動作順序

由影響最小到最大。**每一步都不改動任何字元。**

1. **加寬該框**，同列其他框不動。
2. **標籤換行**並加高該列所有框（同列等高）。
3. **重新分配欄寬**——把該列的水平間距讓給較長的框。
4. **調整字級**，在角色最小值以上微調。
5. **換緊湊 density**（`tight`），縮小內距與列距。
6. **加高畫布**而非加寬。高度不影響相對字級，寬度會。
7. **縮窄畫布並等比放大字級**——相對字級因此提高。這步反直覺但有效。
8. **回報**：以上都不夠時，說明情況並建議分組或拆圖，由使用者決定。

### 換行的規則

換行是排版決定，可以做；改字元不行。

- **不得插入連字號**——那是新增字元。
- CJK 不在行首標點（，。、）前斷，不在行尾開括號後斷。
- 中英混排不從單字中間斷。
- 一個標籤需要三行以上時，那是版面問題，走上面第 6、7 步，不是繼續加行。

### 絕對禁止

縮寫、截斷、加刪節號、改用同義短詞、移除單位、合併兩個標籤。
這些全都是改內容，不是排版。

## 檢查

```bash
python scripts/check_fit.py out.svg --roles cd=body,sb=support,h1=title,rl=section,cap=caption
```

檢查兩件事：每個文字是否達到角色最小字級、每行是否塞得進所屬容器。
`--roles` 把 CSS class 對到角色名；未列出的 class 一律以 `caption` 的
最小值（1.4%）檢查，那是全表最寬鬆的底線。

這是格式建構前置檢查，不是最終 rendered-artifact verdict；交付前仍要執行 `visual-output-qa`。

## 字寬估算

SVG `<text>` 不換行，超出會**靜默**跑出畫布，所以寬度要算不能用看的。

粗體下的每字寬度：

- CJK 字元 ≈ `1.0 × font-size`
- 拉丁字母／數字 ≈ `0.55 × font-size`

**最小卡片寬**：

```
w_min = ceil(((cjk × 1.0 + latin × 0.55) × font_size + 2 × card_pad_x) / 8) × 8
```

例：`語意切片＋向量化` 8 字 × 20px = 160，加寬鬆內距 2×48 → 256。
