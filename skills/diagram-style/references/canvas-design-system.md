# Canvas Design System

Use this reference for **generate** work.
It defines design principles, not a fixed layout or template.

## Design philosophy

Write one concise visual philosophy before drawing.
Define how space, form, colour, scale, rhythm, hierarchy, and balance will communicate the subject.
Use that philosophy as a constraint for every visual decision.

Prefer visual communication over explanatory prose.
Encode meaning through geometric relationships, colour zones, visual weight, repetition, alignment, and negative space.
Keep text essential, concise, and integrated into the composition.
For technical diagrams, retain every label needed to preserve accuracy even when that exceeds a poster-like text ratio.

## Composition

Build from a deliberate grid.
Use consistent margins, spacing intervals, alignments, and shape families.
Establish one dominant focal point, a clear reading path, and restrained secondary detail.
Use scale contrast deliberately: large elements carry the main assertion; small labels anchor interpretation.

Keep every element inside the canvas.
Prevent overlaps, clipping, accidental tangencies, uneven gaps, and arbitrary placement.
Use negative space as structure, not as leftover area.

## Colour

Use a limited palette of two to five functional colours whenever content permits.
Assign each colour a stable semantic role.
Do not use colour as the only information channel; reinforce it with labels, position, shape, line style, or texture.
Use perceptual colour spaces such as OKLCH when creating or adjusting colours, then validate actual contrast in the output medium.

## Typography

Treat typography as part of the visual architecture.
Use a small type scale with clear contrast between title, section, body, support, and caption roles.
Prefer clean sans-serif faces and restrained weights for labels.
Use heavier or larger type only for genuine focal moments.
For CJK text, prioritize legibility over thin-weight styling and follow `typography.md` minimum ratios.

## Systematic rhythm

Use repeated marks, modules, line patterns, or geometric units to establish rhythm when they clarify the subject.
Keep repetitions exact enough to feel intentional.
Dense detail may reward close inspection, but it must not compete with the primary reading path.

Choose an appropriate compositional character:

- Monumental geometry for forceful, high-level assertions.
- Chromatic zones when colour is the primary grouping system.
- Quiet negative space and subtle texture for reflective subjects.
- Rounded modular clusters for organic systems.
- Strict grid and restrained typography for technical or formal subjects.

Do not mix characters without a clear reason.

## Refinement

Use the second pass to refine, not expand.
Correct spacing, alignment, line rhythm, optical centring, hierarchy, and colour balance before adding decoration.
Remove elements that do not explain, orient, distinguish, or focus.

Avoid cartoon styling, random placement, excessive prose, inconsistent spacing, decorative effects without semantic purpose, and obvious template repetition.

## Completion check

- Visual philosophy is visible in the composition.
- Main message is identifiable before reading details.
- Reading order is unambiguous.
- Palette is limited and semantically stable.
- Type hierarchy is clear and legible.
- Repetition and spacing follow a consistent system.
- Nothing overlaps, clips, or falls outside the canvas.
- Final pass improved precision without adding clutter.
