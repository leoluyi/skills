樣式參考

點色票複製 hex。每一項區別在灰階下都必須依然成立。

角色 樣式掛在角色上，不掛在圖元上

區域底一個範圍：階段、泳道、層--cat-N-region
卡片底一個東西：元件、動作、角色--cat-N-card
子卡片巢狀子物件，從屬於某卡片--cat-N-card-sub
邊框／色條解過對比，也用於徽章底與圖示--cat-N-line
主題輸入值只定色相，不直接畫任何東西--cat-N-base

文字　ink-strong 主文字　·　ink-muted 註記　·　badge-ink 徽章字（白或近黑，取對比高者）
單值　canvas 畫布　·　infra 共用設施　·　terminal 終點實心　·　accent 強調，限 3 處　·　highlight 螢光筆，限 2 處
cat-N 無語意　位置槽，意義每張圖各自指派。固定的只有「單圖內獨佔」與「明度遞增」。
