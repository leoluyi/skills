# 閘門清單

`diagram-style` 目前擋得住什麼、擋不住什麼。加規則前先看這裡，
避免重複造閘門，也避免以為某條規則已經被守著。

## `derive.py`（顏色）

| 檢查 | 硬擋 | 門檻 |
|---|---|---|
| `ink` 對每個 card／region | ✓ | 4.5:1 |
| `line` 對 card（邊框可辨） | ✓ | 3:1 |
| `badge-ink` 對 line | ✓ | 4.5:1 |
| 白／近黑對 terminal | ✓ | 4.5:1 |
| 相鄰類別灰階間距 | ✓ | 10%（print 15%） |
| 純框線類別數 | ✓ | ≤3 |
| print 模式畫布 | ✓ | 必須 `#FFFFFF` |
| `vivid` 與 `print` 併用 | ✓ | 互斥 |
| highlight 對 ink／畫布 | ✓ | 4.5:1／1.5:1 |
| 類別明度是否遞增 | 回報 | 並列類別合法不遞增 |
| 類別數 > 5 | 回報 | 讀者負擔 |
| highlight 色相貼近類別 | 回報 | 只影響 `surface/emphasis` |
| 暖色修正是否套用 | 回報 | — |

## `check_fit.py`（文字）

| 檢查 | 硬擋 |
|---|---|
| 字級 ≥ 角色最小比例 | ✓ |
| 文字溢出卡片 | ✓ |
| 文字跑出畫布 | ✓ |
| 最大字級低於 title 門檻（可能沒有 L1 標題） | 回報 |

跳過標了 `aria-hidden="true"` 的裝飾矩形——螢光筆底線、實心陰影不是容器。

## `test_themes.py`（回歸）

19 個基準：6 組主題 + 13 個閘門案例。閘門案例鎖的是**規則本身**，
那些路徑沒有主題檔守著。

## 目前擋不住的

這些規則寫在文件裡但沒有閘門，是下一批該補的：

- **類別色在單張圖內獨佔**——無從檢查，需要圖的語意
- **`accent` ≤3 處、`highlight` ≤2 處**——同上
- **一個表面只有一個意思**（卡片／區域／註解不混用）——需要解析成圖
- **文字零改動**（PPTX 重繪）——`markitdown` diff 可以做，但還沒接進腳本
- **筆調與顏色只換一層**——需要比對前後版本

前三項要檢查得靠解析產出的 SVG 結構，成本高但可行。
第四項最容易補，也最有價值——那是本 skill 的第一條規則。
