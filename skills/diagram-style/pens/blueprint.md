# blueprint — 線稿

純框線、無填色、方正邊角。視覺重量最低。

```yaml
rx: 0
fill: outline
stroke-width: 2
depth: hairline
density: normal
routing: orthogonal
arrow: open
```

**適合**：附錄線稿、黑白影印、需要壓低視覺重量讓正文說話的場合。
方正邊角讀起來像工程圖而非簡報圖——這是刻意的，附錄的工作是被查閱，不是被記住。

## 這是唯一綁定主題的筆調

**必須搭配 `blueprint-mono`**，另外兩種筆調則可自由搭配其餘三組主題。

原因是 `fill: outline` 會**反向限制顏色層**：表面不填色時所有色階塌回畫布，
邊框變成唯一區隔卡片與紙面的東西，對比得對畫布解。
白紙上要 3:1 就限制相對亮度 ≤30%，類別上限因此從 4 掉到 3。

`blueprint-mono` 是唯一為這個限制設計的主題（單色相、三階、全部壓在 30% 以下）。
把 `outline` 套到其他主題上，`derive.py` 會擋下超額的類別，
且淡底全部消失後那些主題的性格也就沒了。

單色相意味著類別只靠明度區分，沒有色相當第二通道——
**編號徽章在這種筆調下是必要的，不是選配**。

## 這種筆調連帶的節奏

虛線長度隨線寬縮放、斜線紋間距隨密度縮放，公式在 `references/layer-pen.md`。
實際值不在這裡手寫——會與公式漂移。看 `docs/style-reference.html`。

`fill: outline` 沒有填色通道，所以 `state/planned` 在這種筆調下改用
**虛線框 ＋ 斜線紋**，而非其他筆調的「虛線框 ＋ 無填色」。
`deprecated` 維持實線框 ＋ 斜線紋，兩者靠邊框樣式分開。
