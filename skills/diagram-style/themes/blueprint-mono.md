# Blueprint Mono — 單色線稿

單一藍色相的三階明度。無填色，純框線。

**適用**：附錄線稿、黑白影印、需要壓低視覺重量讓正文說話的場合。
**不適用**：需要四個以上類別的圖——線稿模式上限是 3。

```
mode: outline
```

> 表面不填色，類別上限 3

## Base 值

```css
:root{
  --cat-1-base:  #0F3157;
  --cat-2-base:  #2367B0;
  --cat-3-base:  #5091D8;
  --infra-base:  #6B7684;
  --terminal:    #0F3157;
  --ink-strong:  #0F3157;
  --canvas:      #FFFFFF;
  --accent:      #B03A2E;
  --highlight:   #CBE2F3;   /* 螢光筆 — 藍 H205 S64 — 單色主題用同色相的淺階 */
}
```

字型：`"Noto Sans CJK TC", "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`

## 為什麼只有三階

線稿沒有淡底，邊框是唯一區隔卡片與紙面的東西，所以對比要對**畫布**解。
白紙上要 3:1 就限制相對亮度 ≤30%，而 0–30 這個範圍放 10% 間距只裝得下三個類別。

灰階明度 **3% / 13% / 27%**，間距 10.2 與 13.7，都剛好在門檻之上——沒有餘裕。
想加第四個類別得先分組或拆圖，`derive.py` 會擋。

## 陷阱

單色相意味著**類別完全靠明度區分**，沒有色相當第二通道。
所以線稿模式下編號徽章不是選配，是必要的——缺了它，
淺藍與中藍在縮圖或低品質影印下會分不出來。
