# Muted Ledger — 帳冊（列印最佳化）

藏青、青、橘。不使用號誌隱喻，適合類別之間沒有時序關係的圖。

飽和度比原色票提高 **×1.35**：初版偏灰褐——低飽和與髒是一線之隔，
而它踩到了髒的那邊。但這是正式文件與列印用的主題，
提太多（試過 ×2.0）會得到 `#FF9B20` 那種亮橘，在簽呈上太吵。
×1.35 是「乾淨但不張揚」的位置。色相與灰階值不變。

**適用**：簽呈、評估報告、需求規格書附圖，以及任何會被印出來或影印的圖。
本 skill 的預設主題，`console`／`briefing`／`ledger` 三個 preset 共用它。

**不適用**：純框線線稿（改用 `blueprint-mono`）；
需與 Bootstrap 或 Tailwind 介面視覺一致時（改用對應主題）。

```
mode: print
```

> 網點下限 8%、灰階門檻 15%、畫布須純白

```css
  --cat-s-base:  #B0342A;   /* 紅，只用於 warning／issue 等異常狀態 */
  --infra-base:  #8A8F96;

  --ink-strong:  #1E2A36;
  --canvas-white: #FFFFFF;   /* 純白＝紙白，列印預設 */
  --canvas-tint:  #F7F5F1;   /* 淡帳冊紙色，螢幕預覽可選 */
  --accent:      #6D63A8;

```

字型：`"Noto Sans CJK TC", "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`

灰階明度 **8% / 26% / 45%**，間距 18 與 19。

## `print: true` 改變了什麼

列印與螢幕有三個不相容的限制，這個旗標一次處理：

**1. 網點下限拉到 8%。** 平版與雷射印不出 8% 以下的網點——不是變淡，
是整片掉字或出現斑駁。色階因此整組上移：

| | 螢幕 | 列印 |
|---|---|---|
| `region` | 4% | **8%** |
| `card` | 10% | **14%** |
| `card-sub` / `region-line` | 16% | **22%** |

代價是階與階之間變近，卡片與區域底的區別在螢幕上會比其他主題弱一些。
這是為紙面付的錢。

**2. 畫布必須是純白。** 印一層 `#FAFAF8` 既費墨，圖與頁面交界處還會出現
看得見的方框。`derive.py` 在 print 模式下會擋下任何非 `#FFFFFF` 的畫布。

**3. 灰階間距門檻從 10% 提到 15%。** 影印比灰階渲染粗暴得多，
二次影印後 10% 的差距常常糊成同一塊。

## 提飽和的做法

**保色相、提飽和、重新解明度把灰階值釘回原位。** 提飽和前後都是 8 / 26 / 45，
所有灰階閘門不受影響。

倍率是看圖決定的，不是算的：把 ×1.0／×1.35／×1.5／×2.0 四檔畫成實際卡片並排。
×1.0 灰褐、×2.0 太亮，×1.35 乾淨且仍克制。**這一項沒有閘門可以代勞。**

直接調飽和度會連帶改變明度，那會打破間距。先記下原本的相對亮度，
提完飽和後二分搜尋新的 HSL 明度，解回同一個值。

列印代價：飽和度越高越費墨，大面積純色在某些印表機上會出現條紋。

## 這組值怎麼來的

初版是 `#3A5678 / #2E7D74 / #A66A4A`，對比全過，
但灰階落在 **9% / 17% / 19%**——青與陶只差 2%，影印後完全糊在一起。

第二版拉開到 **8 / 20 / 47**，螢幕夠用，但套上 print 模式後
cat-1 與 cat-2 只差 12，過不了 15% 門檻。

現在是 **8 / 26 / 45**，間距 18 與 19，兩段接近等距。
色相維持 H214 / H173 / H33 不變，只重排明度。

第四版把飽和度提高 ×1.35。前三版都在調明度，忽略了另一個問題：
低飽和的藏青與陶在小面積卡片上讀起來是灰與褐，不是藍與橘。
**明度分得開，色相卻分不出來**——灰階閘門過了，彩色閱讀時仍然難認。

## 陷阱

`#D9AB72` 對自己的卡片底只有 2 點出頭的對比，只能當邊框。
青色同理。藏青是唯一可以直接寫字的類別色。

三個 preset 共用本主題，所以改動這裡會同時影響 `console`、`briefing`、`ledger`。
改完務必跑 `python scripts/test_themes.py`。
