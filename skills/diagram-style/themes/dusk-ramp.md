# Dusk Ramp — 暮色階（4 類別）

冷到暖的四階：紫灰 → 鼠尾草 → 橄欖 → 琥珀。取自一組七色暮光漸層。

**適用**：類別數 4 的有序流程。這是本 skill 唯一為「多於三階」準備的暖色主題。

**不適用**：純框線筆調（上限 3，改用 `blueprint-mono`）；
類別之間沒有先後關係時——漸層會暗示不存在的順序。

```
mode: vivid
```

> 表面濃度 region 14／card 38／card-sub 50

## 提飽和

原色票的 `#5A6070` 與 `#7B947E` 飽和度只有 **11% 與 10%**——那幾乎是灰色。
連續漸層的中段常有這種近灰過渡色，直接取用會讓圖看起來髒。

已整體提高，**保色相、重新解明度把灰階值釘回原位**，
間距仍是 7 / 27 / 46 / 61，閘門不受影響。

cat-1 提得比其他色多（板岩原本只有 11% 飽和，拉到 45%），
否則藍色會讀成灰色——這正是換掉紫灰的理由之一。

## 來源與取捨

原色票七色連續漸層：`FD4869` `FF8667` `FFC368` `B6BA65` `7B947E` `5A6070` `4D455C`。

**連續漸層不能整條拿來當類別色。** 相鄰兩色的明度差常常不到 10——
`FD4869` (27) 與 `FF8667` (39) 勉強過關，但 `5A6070` (12) 與 `4D455C` (7) 只差 5。
這裡取第 **6、5、4、3** 色——連續的一段，正好是漸層的冷到暖那半。

cat-1 用 `5A6070` 板岩而非 `4D455C` 紫灰：兩者明度只差 5，取哪個都行，
但板岩是藍色相（H224），與其餘三色（H129／H68／H38）相差 96–173°，
比紫灰更能拉開。**色相分離和明度分離要一起看。**

`#FD4869` 玫紅沒有進入平行類別。
它是全組最搶眼的顏色，因此改作 `cat-s`，只標示 warning、issue、error、blocker 與異常狀態。

## 陷阱

`#FFC368` 琥珀對自己的卡片底只有 1.6:1，`#B6BA65` 橄欖 2.2:1——兩者只能當邊框。
藏青與鼠尾草可以直接寫字。

**cat-3 橄欖與 cat-4 琥珀的色相只差 27°**，低於 30° 的準則。
它們靠明度分（46 對 61，差 15）而非色相。這是暖端漸層的固有限制——
原色票在 H36–63 之間就只有這兩個色，沒有第三個色相可換。
四階都要的話得接受這一對偏近；三階就夠時，砍掉橄欖可以讓色相全開。
