## D. 語法／用詞習慣 — 完整版

| 陸式 | 台灣式 | 說明 |
|---|---|---|
| 給到（給到你資料） | 給（把資料給你） | 「動詞＋到」補語濫用 |
| 說到 / 聊到 | 說到 / 聊到 | 台灣亦用,保留 |
| 通過（表手段） | 透過／經由 | 「通過系統查詢」→「透過系統查詢」;表決／通過議案保留 |
| 通過…的方式 | 以…／用… | 刪贅字 |
| 進行＋名詞（進行優化的動作） | 直接用動詞（優化） | 動詞名詞化贅述;與 AI 味重疊 |
| 做出…的決定 | 決定 | 同上 |
| 存在…的問題 | 有…的問題 | 「存在」當贅字 |
| 屬於比較…的 | 比較…／算是… | 刪「屬於」贅字 |
| 是…的一個存在 | 是… | 「存在」名詞化贅述 |
| V＋化 堆疊（場景化、抓手化、顆粒化、賦能化） | 改回動詞或名詞 | 濫用「化」後綴 |
| 立馬 | 立刻／馬上 | — |
| 抓緊（時間） | 趕緊／把握 | — |
| 特／賊（強調副詞） | 超／非常／特別 | 大陸口語 |
| 有點…的意思 | 有點…／稍微… | 口語贅述 |
| 一款（一款產品） | 一項／一個／一款 | 「款」台灣亦用,語境可留 |
| 好好的（好好地說） | 好好地 | 「的／地」區分 |
| 挺…的 | 挺…的／滿…的 | 台灣亦用,保留 |
| 蠻…的 | 滿…的／蠻…的 | 兩者皆通 |

> 「的／地／得」在台灣正體規範中區分較嚴:形容詞＋的、副詞＋地、動詞後補語＋得。大陸網路寫作常混用,順手校正。
