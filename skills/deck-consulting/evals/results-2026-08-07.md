# Results — 2026-08-07, v0.1.0 pre-ship dual run

Baseline: vanilla (no skill loaded), per the repo rule for a brand-new skill.

Harness: Claude Code subagents, same model for both arms, launched together in one dispatch so
neither arm could see the other. Both arms received the case prompt verbatim and were told to reply
as they would to a real user; the with-skill arm was told to read `SKILL.md` and the applicable
reference first. Neither arm wrote to disk — where the skill directs an artifact to a path, the
with-skill arm stated the path and showed the contents inline.

Coverage: cases 1, 3, 4, 5 of the seven in `evals.json`. One repetition per arm. Cases 2, 6 and 7
were not run.

## Per-case

| Case | What it guards | With-skill | Vanilla | Margin |
|---|---|---|---|---|
| 1 溝通定位 from raw material | generic deck coaching; unflagged unverified figure | 7/7 | 4/7 | decisive |
| 3 主張式標題, direction but not magnitude | escalation past the evidence | 6/6 | 5/6 | narrow |
| 4 故事線 with the prerequisite absent | blocking, and inventing the missing context | 6/6 | 4/6 | decisive |
| 5 逐頁診斷 from a description | fabricated rendering findings | 6/6 after fix, 4/6 before | 4/6 | decisive |

**Case 1.** Vanilla gave strong substantive advice — it caught the 8.4-year payback problem and the
資訊處長 blocking risk unprompted — but produced no durable standard: no named starting point, no
floor that survives refusal, no file. With-skill produced the three-tier brief, three postures each
with a sample line in the presenter's voice, and the artifact path. Both arms flagged the
self-calculated 90 萬. Vanilla failed `one-named-starting-point`, `floor-survives-refusal`,
`says-where-it-wrote`.

**Case 3.** Both arms held the evidence line, and vanilla's first option
「兩家試點客戶回報處理時間下降，初估 15–20%」 is a correct answer. Vanilla also warned against
「證實」「顯著」 without being asked. The margin is one assertion: with-skill caught that 翊宸 not
having reported is either a timing fact or a negative result, and that which one it is changes the
title — vanilla treated the absence as a presentational gap to explain rather than as a fork in the
claim. Reported as narrow because it is.

**Case 4.** Vanilla delivered an ordered agenda with timings and readable transitions, and named the
missing numbers. It also invented an ask ("請您裁示要走哪一個") and a budget-routing question the
user never mentioned, failing `no-invented-context`, and never named what the missing groundwork
actually costs. With-skill left every unknown as a bracketed slot, said explicitly that without an
agreed standard any ordering is only decoration, and put the ask back as the one open question. It
also produced a 中斷韌性 read — what the presenter has banked if the meeting is cut short at each
boundary — which is the single most useful thing either arm produced for a 30-minute run-through.

**Case 5.** Vanilla asserted 「九欄在會議室後排讀不到」 and 「投影必爆」 from a verbal description
containing no type sizes, no room dimensions and no images: two fabricated rendering findings, the
exact failure this case exists to catch. It also never established the viewing condition it was
assuming. With-skill asserted no rendering fact and marked every inference — but its first pass
stopped to ask the viewing-condition question and delivered only three of eight pages, failing
`content-findings-still-land` and `clean-pages-named`.

## Defect found and fixed

`references/slidecheck.md` treated the viewing-condition question as a gate, which contradicts the
skill's own no-node-blocks rule and cost the user a turn for nothing. Changed to: state the
assumption, ask in the same breath, deliver the full review in the same reply, mark the findings
that would flip. The re-run cleared all six of case 5's expectations — full eight-page review,
ranked 讀不到／讀錯／讀得慢, every rendering-dependent finding marked 推測 and phrased as a
ten-second confirmation, and a 維持現狀 list naming the pages not worth rebuilding.

## Dispositions

- Cases 2, 6, 7 unrun — moved to `backlog.md`, next round.
- Single repetition per arm — accepted for the three decisive cases, flagged for case 3.
- Three conformance-phrased expectations (`one-named-starting-point`, `says-where-it-wrote`,
  `viewing-condition-settled`) kept but logged in `backlog.md` for rephrasing as reader outcomes.

## Contamination

One agent authored the skill, the eval fixtures and this comparison. The qualitative judgments carry
author bias and this run supports "the skill beats vanilla here", not a general claim of quality. The
deterministic parts are not subject to that bias: whether a figure survived verbatim, whether a
rendering claim was asserted from a description containing no rendering information, and whether
context absent from the prompt appeared in the reply are all checkable against the transcripts by
someone who never read the skill.
