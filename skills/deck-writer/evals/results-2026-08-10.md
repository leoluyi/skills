# Behavior Evaluation: 2026-08-10

## Setup

Baseline: vanilla agent behavior with no deck-writing skill loaded.

Skill arm: fresh Codex subagents received the three raw user prompts and read only `SKILL.md`.

Vanilla arm: fresh Codex subagents received the same raw user prompts and read no skill or evaluation fixture.

Repetitions: two independent runs per arm.

Judge: Claude CLI, blind to arm identity, with only `evals.json` and anonymized outputs.

Contamination: the root session authored both the skill and fixture.
Generation agents and judge were independent, but the evaluation can show that the skill adds the predeclared mechanisms, not universal superiority.

## Results

| Case | Set 1 | Set 2 | Deciding evidence |
|---|---|---|---|
| 1: observability approval deck | skill | skill | Skill outputs consistently supplied purpose, layout cue, source notes, evidence gaps, and explicit refusal to invent numeric commitments. One vanilla run invented 30%, 30-minute, and 100% targets. |
| 2: passkey webinar outline | skill | skill | Skill outputs used assertion-style claims with each slide's job, required evidence, and proposed form, while preserving the missing-notes and legal-approval boundaries. |
| 3: unresolved audience and duration | skill | skill | Skill outputs explained how each audience and duration choice changes the storyline, evidence, and depth, asked for the desired outcome, and avoided assigning an unsupplied slide count. |

Combined: skill arm won six of six paired case judgments.

## Protection failures

No skill-arm output invented a target, customer fact, or production artifact in the final comparison.

One vanilla output added unsupported goals of reducing unlocatable alerts below 30%, reducing average localization time below 30 minutes, and reaching 100% correct alert handling.

The same vanilla output added a 30-day measurement window without source support.

Another vanilla passkey outline claimed reduced user friction while also stating that the product notes were unavailable.

## Disposition

Keep the evidence-boundary language that prohibits unsourced numerical targets, schedules, severity labels, and implementation details.

Keep the outline checkpoint as one compact row per slide with claim, job or evidence, and content form.

Keep the clarification path that explains option consequences without inventing slide counts from speaking time.
