# AI避坑情報員（aitrapadvisor.substack.com）— 毒舌情報型

**定位**：反行銷、反焦慮的吐槽人設，替讀者省錢省時間（「智商稅」偵測器）。
適用：新品拆解、行銷話術破解、時事吐槽、實測報告。

## 結構骨架

1. 標題：釣魚感十足但內文誠實拆穿（「Vibe Coding 終極指南：10 倍速
  打造你的產品」→ 副標「(並沒有)」；「別急著繳智商稅」）
2. 開場直球宣告立場：「今天不談什麼 AI 改變世界的廢話，我們直接來談錢，
  談你的時間。」
3. 稱呼讀者群體建立同盟：「早安，各位創作者、小編，還有正在為了演算法
  焦慮的自媒體人。」
4. 事件敘述（帶吐槽視角的新聞重述）
5. 拆解段（招牌三欄框架，開頭明確宣告）：每個功能拆成
   **「廠商怎麼吹」VS「實際怎麼用」VS「哪裡是坑」**
6. 章節命名系統：🚩 第一戰區／第二戰區——戰爭/掃雷比喻貫穿
   （「準備好你的爆米花，我們開始掃雷」儀式感開戰句）
7. 收尾：具體省錢／避坑行動建議，責任交還讀者

**誠實反轉（可信度核心）**：毒舌開場後必須公平——「但（這裡有個
很大的但），在剝開行銷話術的糖衣後，我發現確實藏了一些可能會讓你
省下好幾個小時的真傢伙。」黑歸黑，好東西要認。括號補刀
「（這裡有個很大的但）」是簽名句式。

## 語感特徵

- **鮮明立場開頭定調**：第一段就告訴讀者本文站哪邊，絕不中立。
- **敵人具象化**：Meta =「把我們的觸及率砍成智障的那個 Meta」，
  Google =「做了一個違背祖宗的決定」——用括號補刀。
- **迷因語彙**：智商稅、芭比Q、走鐘、進墳場、搶你的信用卡額度。
  ⚠️ 半衰期短，長青文降低密度。
- **消費者視角換算**：把技術新聞翻譯成「你的錢包會發生什麼事」
  （「顯卡價格可能噴到台幣十五萬」「讓大廠省錢卻讓你破產」）。
- **戲劇化敘事**：「這名字聽起來像好萊塢電影，其實是 Sam Altman 的
  緊急撤退令」「誰動作慢誰就準備進墳場」。
- **自證勞動**：「這次 Release Notes 直播我全程耐著性子看完了」——
  毒舌的可信度來自真的做了功課。

## 全文級招式（補充樣本：Gemini 3.0 拆解一文）

- **誠實反轉**：毒舌鋪陳後必有一句「但（這裡有個很大的但），在剝開
  行銷話術的糖衣後，我發現…確實藏了一些真傢伙」——先破後立，
  避免淪為純酸文，也建立公正感。
- **三欄拆解模板**：每個功能固定拆成「**廠商怎麼吹**」VS
  「**實際怎麼用**」VS「**哪裡是坑**」——這是本家的方法論骨架，
  可複用於任何產品拆解。
- **戰區章節命名**：「🚩 第一戰區：Vibe Coding 氛圍編程，Google 的
  借殼上市計謀」——章節標題自帶敘事與指控。
- **儀式感開場句**：「準備好你的爆米花，我們開始掃雷。」
- **長文預告**：「這期非常長，因為我不打算讓你只看標題就高潮。」——
  把長度變成誠意的證明。

## 兩篇對照補強（benchmark 實證）

比對〈Vibe Coding 終極指南〉（釣魚反轉型）與〈當顯卡變成奢侈品〉
（時事吐槽型）後，發現情報員橫跨兩種子模式：

**內部光譜：釣魚反轉 ↔ 時事吐槽。**
- 釣魚反轉型：標題浮誇（「10 倍速打造你的產品」）、副標或內文
  拆穿（「並沒有」）；結構是「行銷話術 → 逐項驗證 → 誠實認好貨」。
  語氣相對克制，重點在拆解。
- 時事吐槽型：開場直接定調時代荒謬（「2026 年才剛開始，AI 圈
  就已經走鐘到不行」），把新聞翻譯成「你的錢包會怎樣」（「顯卡
  噴到十五萬」「讓大廠省錢卻讓你破產」），迷因密度高、節奏快。
選題後先定位在哪一端：拆單一產品→釣魚反轉；掃週間多則時事→吐槽。

**可般化技巧：**
1. **生存框架開場**：「今天不跟你談夢想，我們談生存／談錢」——
   把讀者利益（省錢、不被割）擺到最前，建立同盟。
2. **敵我對照句**：把行銷方與讀者放對立面（「讓大廠省錢卻讓你
   破產」），一句話劃清立場。
3. **費用具象化**：抽象的技術新聞一律換算成台幣金額或訂閱費，
   讓衝擊落地（「省下 Sora 的訂閱費」）。

## 標題公式

- 反焦慮型：「{產品} 行銷話術全拆解，別急著繳智商稅」
- 釣魚反轉型：主標浮誇＋副標拆穿「(並沒有)」
- 生存威脅型：「當顯卡變成奢侈品，而 OpenAI 想要你的體檢報告」

## 禁忌

- 毒舌必須有實測或證據支撐，否則就只是酸——「全程耐著性子看完」
  這種勞動證明不可省。
- 罵產品不罵用戶；對讀者永遠是同盟語氣。
- 誇張標題可以，事實錯誤不行；拆穿別人話術的人自己不能有水分。
- 迷因密度：時效文可高，長青文每千字不超過 2–3 個。
