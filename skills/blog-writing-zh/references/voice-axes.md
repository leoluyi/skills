# Style Menu — 風格選單：元素拆解與 Presets

風格 = 八個元素的組合。Preset 是經過驗證的元素配方，供**單選**使用；
進階使用者可在 preset 基礎上覆寫個別元素。

## 選單互動流程

1. 預設走 **preset 單選**：列出五個 preset（名稱＋一句話定位＋適用
   文章類型），外加「自訂配方」選項。在支援選單工具的環境
   （如 AskUserQuestion）用單選呈現；否則以編號清單詢問。
2. 使用者選 preset → 直接套用，不再逐項確認。
3. 使用者選「自訂配方」→ 逐元素詢問（一次最多三個元素，先問
   影響最大的：結構框架、人設濃度、比喻型態）。
4. 使用者說「照上次」→ 讀取前次輸出的風格配方紀錄沿用。
5. 每次輸出文末附「風格配方紀錄」（preset 名或八元素明細）。
   連續三篇同配方 → 視為個人預設，之後主動沿用只確認差異。

## 八元素拆解

### E1 開場策略
| 選項 | 說明 | 代表 |
|---|---|---|
| 場景鉤子 | 一幕有張力的場景／一句引語破題 | 倉鼠 |
| 契機→痛點→承諾 | 個人動機、具體卡關、本文目標，一段完成 | 保哥 |
| 直球宣告 | 第一句就定立場（「今天不談廢話，直接談錢」） | 情報員 |
| 讀者內心 OS | 條列讀者的抗拒反應，先接住再論證 | 高見龍 |
| 回顧→問題化→三問 | 系列文：上篇急停回顧、指出致命問題、承諾回答三問 | 90s.pm |

### E2 人設濃度
- **L1 收斂**：第一人稱只在開頭動機與結尾心得；正文專業中性、用「您」。
- **L2 中等**：正文穿插判斷句與低劑量口語（一篇 1–3 處），偶爾自嘲。
- **L3 高濃度**：全程對讀者喊話、吐槽、玩梗、括號補刀。

### E3 比喻型態
| 選項 | 說明 | 代表 |
|---|---|---|
| 無／極少 | 靠精確定義與範例，不造喻 | 保哥正文 |
| 一句話類比 | 難概念配一句類比（「像從不疲憊的紀律委員」） | 倉鼠 |
| 劇情式故事 | 比喻是有角色情節的小故事，講完回收一句（小吃店收到武功秘笈→「Skills 就是這本秘笈」） | 高見龍 |
| 系統級詞彙 | 自建比喻詞彙表全文貫穿、反覆呼叫（樹/葉/燈號；戰區/掃雷），中途不可換喻 | 90s.pm、情報員 |

### E4 節奏設計
- **平穩**：段落長度一致，教學文標配（可重現優先）。
- **短段留白**：1–3 句一段，金句放引用區塊前後留白。
- **急停對比**：長段落後接單句段甚至單字句（「上一篇我們做了一件事：猜。」）。

### E5 結構框架
| 選項 | 說明 | 代表 |
|---|---|---|
| 主題章節 | H2/H3 依概念推進，問句轉場 | 倉鼠 |
| 糾錯式教學 | 先打掉錯誤心智模型（「別再把全螢幕當最大化！」）→ 核心觀念條列 → 實戰 → 術語對照表 | 保哥 |
| 藉口擊破 | 主論證後，預判反駁逐一擊破（H4 引號小標） | 高見龍 |
| 三欄拆解 | 每項目「廠商怎麼吹 VS 實際怎麼用 VS 哪裡是坑」，章節用戰區命名 | 情報員 |
| 零件化框架 | 方法拆成零件一/二/三，每零件：定義→錯誤示範→正確示範 | 90s.pm |
| 演進敘事 | 三階段歷史脈絡定位新事物（一問一答→Tool Calling→Skills） | 高見龍技術文 |

### E6 術語處理
- **三層法**（預設）：首現「中譯（English）」；無定譯保留英文；關鍵概念加白話註解。
- **對照表**：文末附精準術語表（正確中文｜英文｜常見誤稱｜說明）。
- **白話翻譯句**：官方定義後接「翻成白話文就是…」。

### E7 收尾方式
| 選項 | 範例 |
|---|---|
| 宣言金句 | 「當程式碼免費，問問題的能力才是稀缺品。」 |
| 觀念總結＋祝福 | 「理解了以空間為核心的哲學後…希望能幫助大家！👍」 |
| 責任交還讀者 | 「樹不會替你簽下那張買單。」＋具體行動建議 |
| 留鉤子預告 | 「下一篇我們來講講怎麼真正開始動筆。」 |

### E8 標題公式
如何型（保哥）／解密型（保哥）／大哉問型（倉鼠）／二元對立問句型
（90s.pm）／反焦慮拆解型（情報員）／祈使稱呼型（高見龍）／
釣魚反轉型（情報員，主標浮誇副標拆穿）。

## 兩層選單：文章類型 × 風味

Preset 重新設計為兩層，解耦「用途」與「口味」：

**第一層（必選，單選）＝文章類型**：決定結構框架、技術描述模式、
收尾方式等骨架元素。
**第二層（可選，單選）＝風味 flavor**：套用某位作者的語感細節
（讀對應 style-*.md）。可選「無特定風味」，此時只用八元素預設。

### 第一層：文章類型 preset

| Preset | 用途 | tech-writing 模式 | 骨架預設（E1/E4/E5/E7） | 建議風味 |
|---|---|---|---|---|
| 教學實作型 | 教學、設定、工具導入 | 操作型 | 契機痛點承諾／平穩／糾錯式教學／總結祝福 | 保哥、Simon |
| 概念導讀型 | 新概念、選型、易混淆梳理 | 概念型 | 讀者OS或TL;DR／短段留白／主題章節＋定位澄清／判斷標準收尾 | 高見龍、Julia |
| 深度解讀型 | 原理、翻譯改寫、趨勢 | 推演型 | 場景鉤子／短段留白／主題章節／宣言金句 | 倉鼠、Julia |
| 實測筆記型 | TIL、上手紀錄、快評 | 操作型（輕量） | 具體情境開場／平穩／情境→解法→指令／自我連結 | Simon |
| 觀點倡議型 | 主張、成長、方法倡議 | （視內容）概念型 | 讀者OS／急停對比／藉口擊破／留鉤子或宣言 | 高見龍、倉鼠 |
| 拆解評測型 | 產品拆解、行銷破解 | 概念型＋實測 | 直球宣告／急停對比／三欄拆解／責任交還 | 情報員、Simon |
| 分析框架型 | 分析、決策、框架教學 | 概念型 | 回顧問題化三問／急停對比／零件化框架／責任交還 | 90s.pm |

E2（人設濃度）、E3（比喻型態）、E6（術語）、E8（標題）由風味決定；
選「無特定風味」時預設 L2／一句話類比／三層法／依類型公式。

### 選單互動（更新版）

1. Q1 單選文章類型（7 選項，或依上下文先推薦 1 個讓使用者確認）。
2. Q2 單選風味：只列該類型的 2–3 個建議風味＋「無特定風味」，
   不要七個全列。
3. Q3 單選長度檔位（短打／標準／深文／工具書級），附依類型的
   推薦預設。三問可在同一輪選單一次問完。
4. 「自訂配方」與「照上次」機制不變（見上方選單互動流程）。
5. 配方紀錄格式：`類型｜風味｜長度檔位｜覆寫元素（若有）`。

### 舊 preset 對照（向後相容）

倉鼠敘事型＝深度解讀型×倉鼠；保哥教學型＝教學實作型×保哥；
高見龍對話型＝觀點倡議型×高見龍；90s方法論型＝分析框架型×90s.pm；
情報員毒舌型＝拆解評測型×情報員。使用者講舊名直接映射，不需追問。

### 元素相依守則

覆寫元素時保持 E3+E5 成套（三欄拆解搭戰區詞彙、零件化搭系統級
比喻）；風味的 E2 人設濃度與文章類型衝突時（如教學實作型×情報員），
以文章類型的可操作性要求為上限——教學正文不得因風味犧牲可重現性。
