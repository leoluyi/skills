# Layer: Pen — 筆調層

角色 → 幾何。每個角色該有什麼圓角、線寬、線型、間距。

角色定義在 `roles.md`；媒材實作在 `render-svg.md` 與 `render-pptx.md`。

**不叫「形狀」是刻意的。** 真正的形狀——圓柱、雙線框、實心終點——承載意義，
由角色決定，不在這一層。這一層管的是**不改變圖在說什麼、只改變它說話方式**的部分：
線多粗、角多圓、擺多鬆。換筆調不換內容。

因此「加個膠囊形／菱形／六角形選項」這類請求要擋下來：那些在流程圖慣例裡
都已有語意（膠囊＝起訖端點、菱形＝決策），當成風格選項會把訊號洗掉。
真要新增，走**新角色**的路，像 `datasource`、`gate` 那樣附語意理由。

## 不可調的部分

先劃界線。以下節點形狀**承載意義**，不屬於這一層，任何 preset 都不得覆蓋：

| 元素 | 為什麼固定 |
|---|---|
| `datasource` 圓柱 | 編碼「這是資料源」，換成矩形就消失了 |
| `gate` 雙線框 | 編碼「這裡需要人為核准」 |
| `terminal` 實心 | 編碼「這是終點」，且全圖唯一 |
| 卡片／色帶／虛線框三分 | 編碼「東西／範圍／註解」，混用會讓讀者把註解讀成元件 |
| 邊框顏色 | 由 `line` 推導，屬顏色層 |

想調這些就是想改變圖在說什麼，不是改樣式。

## 可調的部分

| Token | 選項 |
|---|---|
| `rx` | 0（方正）／4（微圓）／6／12（柔和） |
| `fill` | `filled`（淡底）／`outline`（純框線，無填色） |
| `stroke-width` | 1（框架風，Bootstrap／Tailwind 預設）／1.5（細）／2（標準）／2.5（粗） |
| `depth` | `hairline`（細框）／`shadow`（柔和陰影）／`solid`（實心偏移色塊）——**三選一，不可並用** |
| `density` | `tight`／`normal`／`loose`，見下表 |
| `routing` | `orthogonal`（直角折線）／`straight`（直線）／`curved`（曲線） |
| `arrow` | `solid`（實心三角）／`open`（開放 V 形） |

`rx` 一律等比套用：子節點比主節點小 2，色帶區域比主節點大 2。
單獨調某一個會讓層級關係斷掉。

## fill 會影響顏色層

**`outline` 不只是把填色拿掉。** 表面不填色時所有色階都塌回畫布，
邊框變成唯一區隔卡片與紙面的東西，對比就得對**畫布**解，而不是對一個已經不存在的淡底。

後果是類別上限從 4 掉到 3：邊框對白紙要 3:1 限制了相對亮度 ≤30%，
而 0–30 這個範圍放 10% 間距只裝得下三個。

`derive.py` 讀到主題檔含 `outline: true`（或帶 `--outline`）時會自動切換，
並把上限改成 3。**這是兩層唯一的耦合處**，其餘部分筆調與顏色互不影響。

## 狀態與線條的節奏隨筆調縮放

狀態與線型不是獨立的一層——它們的**語意固定，參數跟著筆調走**。
`6 4` 的虛線在 1.5px 線上讀起來是虛線，在 2.5px 線上讀起來是粗塊：
間隔沒有跟著線寬長大，節奏就消失了。

**虛線陣列 = 線寬的倍數**：

| | ×1.5px | ×2px | ×2.5px |
|---|---|---|---|
| `line/control` 虛線 | `6 4` | `8 5` | `10 7` |
| `line/reference` 長虛線 | `10 5` | `13 7` | `17 8` |
| `line/optional` 點劃線 | `8 3 2 3` | `11 4 3 4` | `13 5 3 5` |
| `line/leader` 點線 | `2 3` | `3 4` | `3 5` |

係數是 `4/2.7`、`6.7/3.3`、`5.3/2/1.3/2`、`1.3/2`。
本 skill 文件裡寫死的那組數字（`6 4`、`10 5`、`2 3`）正好是 sw=1.5 的結果——
也就是 `console` 的線寬。那些數字一直都是照 console 校準的，只是先前沒標明。

**斜線紋間距 = 卡片高度 ÷ 8**：tight 5、normal 6、loose 7。
跟著卡片長大，紋理的相對密度才不變。紋理要夠疏——密到看起來像實心填色時，
讀者會以為那是另一個類別，而不是同一元件的退場狀態。

## 純框線筆調的狀態覆寫

`fill: outline` 沒有填色通道可用，`state/planned` 的「無填色」失去區別力。
該筆調下 `planned` 改用**虛線框 ＋ 斜線紋**，`deprecated` 維持**實線框 ＋ 斜線紋**。

四種狀態在該筆調下的通道：

| | 邊框 | 紋理 |
|---|---|---|
| 一般 | 實線 | 無 |
| `external` | 虛線 | 無 |
| `planned` | 虛線 | 有 |
| `deprecated` | 實線 | 有 |

每一對至少差一個通道，灰階下仍分得開。

## `depth: solid` — 實心偏移陰影

卡片後方一個偏移的實心色塊，用 `highlight` 色。這是 `surface/emphasis` 的做法。

```xml
<rect x="{x+6}" y="{y+6}" width="{w}" height="{h}" rx="{rx}" fill="var(--highlight)"/>
<rect x="{x}"   y="{y}"   width="{w}" height="{h}" rx="{rx}"
      fill="var(--cat-N-card)" stroke="var(--cat-N-line)" stroke-width="{sw}"/>
```

偏移量固定 6，右下方向。**偏移不隨 density 變**——變了就成了另一種強調程度，
而強調只該有「有」與「沒有」兩種狀態。

PPT 用原生陰影而非疊兩個圖形：`shadow` 設為實心、模糊 0、距離 6、角度 45。
**offset 不可為負**，會損毀檔案。

## 空間骨架

基準單位 **8**。所有座標為 8 的倍數，含畫布尺寸。

`density` 一次決定五個值。**不要單獨挑**——只縮高度不縮間距會讓圖看起來被壓扁。

| Token | `tight` | `normal` | `loose` |
|---|---|---|---|
| `card-h` / 單行 | 40 | 48 | 56 |
| `card-h` / 雙行 | 56 | 64 | 72 |
| `card-pad-x` | 24 | 48 | 56 |
| `card-gap-x` | 32 | 40 | 48 |
| `row-gap` | 40 | 56 | 64 |

雙行一律是單行 +16，那是 20px 內文加 1.15 行高再對齊 8 格線的結果。

其餘不隨 density 變：
| `region-pad` | 16 |
| `region-rx` | 12 |
| `accent-bar-w` | 6 |
| `accent-bar-rx` | 3 |
| `line-height` | 1.15（標題）／1.4（內文） |

**畫布**：`viewBox="0 0 W H"`，省略固定 `width`／`height`。
內容變多時放大畫布並維持間距，不要壓縮間距。

## 連接線

連接線的線寬**跟隨卡片**。兩者不同寬時，圖看起來像兩套系統疊在一起——
`console` 的 1.5px 細框配 2px 連線，線會顯得比框重，視線被拉到連線上。


| Token | 值 |
|---|---|
| `connector-w` | **跟隨 preset 的 `stroke-width`** |
| `connector-cap` | `round` |
| 走線 | 正交折線；轉角半徑 8 |
| 實線 | `line/flow` — 主資料流 |
| 虛線 `6 4` | `line/control` — 控制流、非同步、回饋 |
| 長虛線 `10 5` | `line/reference` — 邏輯關聯、參照 |
| 點劃線 `8 3 2 3` | `line/optional` — 條件性連線 |
| 點線 `2 3` | `line/leader`／`line/boundary` — 註解引線、包含邊界 |

**機制用 dash，非機制用 dot。** 完整角色定義見 `roles.md`。

箭頭 marker 每種顏色各定義一次：

```xml
<marker id="ah" viewBox="0 0 10 10" refX="9" refY="5"
        markerWidth="7" markerHeight="7" orient="auto-start-reverse">
  <path d="M0 0L10 5L0 10z" fill="var(--connector)"/>
</marker>
```
